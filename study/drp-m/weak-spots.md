# DRP-M — Weak Spots

A Weak Spot is a Sub-point where a Drill or the Practice Paper showed a gap, or where a lookup
in the Reference Pack failed (PRD FR-10). Each one is fixed in the pack (a Cheatsheet end point,
the contents page or the keyword index), and the **Fix** column names the content ID changed.

Built 9 Nov 2026 (Phase 1: headings only). Entries start in Phase 2, with the first Drill or
Practice Paper.

## Log

Kinds: `wrong law`, `missed issue` or `failed lookup`. Fix: the content ID, plus what changed
(`keywords` / `title` / `body` / `cheatsheet` / `new block`).
